# 应用商店文案草稿（简体中文）

供 Google Play 与 App Store 使用的草稿。每一条都对应手机应用目前已有的功能
（见 [mobile-prototype.md](../mobile-prototype.md) 与
[architecture-v2.md](../architecture-v2.md)）；应用尚未在真机上运行过，提交前请
对照真实构建逐条核对。这里没有承诺托管服务、手机上的团队保险库、远程转发或
文件夹传输，因为手机上没有这些功能。

## 名称

AnixOps SSH

## 简短说明（Google Play，不超过 80 字）

手机上的 SSH 终端、文件和端口转发，主机与密钥加密保存在本机。

## 副标题（App Store，不超过 30 字）

SSH 终端与文件管理

## 完整说明（不超过 4000 字）

AnixOps SSH 是一款开源的手机 SSH 客户端。主机、密钥和密码加密保存在你的设备
上；除非你自己配置同步到自己搭建的服务器，否则不会向任何地方发送数据。

终端
- 完整的终端，带有 Esc、Tab、Ctrl、方向键等屏幕键盘缺少的按键栏，按键栏可自定义。
- 支持屏幕键盘和输入法，包括中文输入。
- 触摸选择文字（带拖动手柄），复制粘贴，单指或双指滚动，双指缩放字号。
- 平板上支持外接键盘快捷键。
- 可接入 tmux 或 screen；网络中断或应用从后台返回时自动重连。

文件
- 通过 SFTP 浏览服务器，新建文件夹、重命名、删除（删除前会确认），上传和下载文件。

端口转发
- 本地转发（ssh -L），每条转发有独立开关，失败时显示原因。

主机
- 保存主机，支持分组、标签和收藏；可按名称、地址、分组或 #标签搜索。
- 可经由另一台已保存的主机跳转连接（跳板机）。
- 同一主机上的终端、文件和转发共用一条连接，只需登录一次。
- 校验主机密钥，首次遇到新密钥时会先询问你。

保险库与隐私
- 保存的密码、私钥和密钥口令在设备上加密，密钥由 Android Keystore 或 iOS 钥匙串保管。
- 可设置保险库口令，并用指纹或面容解锁；没有传感器验证就无法取出密钥，口令始终可作为备用。
- 应用进入后台时保险库自动锁定。
- 崩溃报告会在首次启动时征求你的同意，匿名使用统计默认关闭，由你决定是否开启；
  终端内容、主机名和地址永远不会被收集。

同步
- 可选：通过你或团队自己部署的开源 AnixOps SSH 服务器，在多台设备间同步主机。
  数据端到端加密，服务器无法读取。

开源
- 应用、同步服务器和协议均为开源，源码见 https://github.com/AnixOps/EasySSH

## Google Play 分类与标签

分类：工具（如有“开发者工具”则选之）。标签：SSH 客户端、终端模拟器。

## 更新内容（首个版本）

手机版首发：SSH 终端、SFTP 文件、本地端口转发、跳板机、带生物识别解锁的加密
保险库，以及可选的、与你自己服务器之间的端到端加密同步。

## 审核表单备注

- 加密：应用使用标准加密（SSH、TLS，保险库使用认证加密），出口合规
  问题据此填写。
- 数据安全 / 隐私：默认没有任何数据离开设备。用户可选：崩溃报告和匿名使用统计
  （见 [telemetry.md](../telemetry.md)），以及同步到用户自己的服务器。
- 权限：网络；生物识别（Face ID 用途说明已在 iOS 工程中）；Android 上可选的前台
  通知（默认关闭），用于让会话在后台保持。
- 审核人员访问：应用需要 SSH 服务器，请在审核备注中提供测试主机和账号。
