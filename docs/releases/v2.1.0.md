## AnixOps SSH 2.1.0

### 新功能 / What's new

- **FIDO2 安全密钥** FIDO2 security keys (`sk-ed25519`, `sk-ecdsa`) work on
  the built-in engine on every desktop platform: over USB on Linux and macOS,
  and through the Windows WebAuthn API on Windows. Touch and PIN prompts
  appear in the app.
- **用安全密钥解锁保险库** Unlock the vault with a FIDO2 security key
  (hmac-secret). The stored copy of the vault key cannot be opened without
  the key itself. Up to four keys can be enrolled; the passphrase stays as a
  fallback.
- **更稳的后台服务交接** Starting a new version while an older background
  service is idle now always hands over cleanly.

### 手机版预览 / Mobile preview

The Android and iOS apps are built from this release but have not yet been
tested on real devices, so they are a preview and are not in the stores yet.
They share the desktop's engine and include:

- a terminal with IME support, a customisable key bar, touch selection,
  pinch-to-zoom and automatic reconnect to tmux or screen;
- hosts with groups, tags and jump hosts (each hop uses its own saved login);
- files over SFTP, and local, remote and SOCKS forwards on one connection per
  host;
- an encrypted vault in Android Keystore or the iOS Keychain with fingerprint
  or face unlock;
- end-to-end encrypted sync with your own server.

Signed Android builds and TestFlight uploads start once the signing secrets
in RELEASING.md are configured.
