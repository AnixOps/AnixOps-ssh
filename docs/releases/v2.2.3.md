## AnixOps SSH 2.2.3

### 终端 / Terminal

- **字体与光标** Pick any installed monospace font, set the line height, and
  choose a block, bar or underline cursor, blinking or not.
- **查找** The find bar gains match case, whole word and regular expression
  toggles, with a match count.
- **⌘K 清屏** On macOS, ⌘K clears the screen and scrollback; the prompt
  line stays.
- **大量输出更流畅** Output is written once per frame, so a flood of output
  no longer stalls the window.

### 文件 / Files

- **多选** Select several files with Shift and Ctrl/⌘ click, or select all,
  then download or delete them together.
- **属性与改权限** A properties dialog shows size, owner and times, and can
  change permissions, for one file or a whole folder.
- **重命名即移动** Renaming to a path in another folder moves the file there.
