## AnixOps SSH 2.3.0

### 新功能 / What's new

- **快速连接** Type `user@host:port` in the command palette to connect
  without saving a host first, and open `anixops-ssh://user@host:port`
  links from a browser or chat.
- **远程编辑** Open a remote file in your local editor (or one you set in
  Settings); each save uploads it again, and a change on the host is
  caught before it is overwritten.
- **文件面板跟随终端** The files pane can follow the folder the terminal is
  in (needs shell integration for the host).
- **终端内 rz/sz** ZMODEM uploads and downloads inside the terminal: run
  `rz` or `sz` on the host and pick or save files locally, with progress
  and cancel.
- **服务器监控** The monitor pane also works for hosts on the OpenSSH engine,
  and the mobile app shows a compact monitor card.
- **Unix socket 转发** Forward a remote Unix socket (for example the Docker
  socket) to a local port, or a local port to a remote socket.
- **X11 转发** Hosts can turn on X11 forwarding; those sessions run on the
  OpenSSH engine.

### 说明 / Notes

- trzsz is not supported yet; rz/sz covers ZMODEM.
