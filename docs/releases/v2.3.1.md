## AnixOps SSH 2.3.1

### 改进 / Improvements

- **监控栏可收起、可调宽** The server monitor folds into a narrow rail that
  still shows CPU, memory, swap, disk and latency, and its edge can be
  dragged to resize it (double-click for the default width). The width and
  folded state are remembered.
- **监控栏布局** Labels and values no longer overlap, hosts and paths are cut
  in the middle so their end stays readable, sizes read `2.8 GB`, the
  process list sorts by its column headers, and in-memory file systems
  (`/run`, `/dev/shm`, efivars) are left out of the disk list.
- **广播输入更清楚** Broadcast is now one labelled "广播 / Broadcast" menu
  that says where typing goes (this tab's panes or every terminal) and how
  many terminals that is. It is off with only one terminal open, and while
  it is on a bar above the terminals says so, with "停止广播 / Stop
  broadcast" beside it.
- Thin scrollbars throughout the app.
