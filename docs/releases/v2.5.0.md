## AnixOps SSH 2.5.0

### 界面 / Interface

- **新图标** AnixOps SSH has its own product icon (a prompt and block
  cursor on a teal-to-green tile) on desktop, iOS, Android and in the app.
- **终端占满窗口** Opening a session folds the host list away so the
  terminal gets the width (at 1200 px: 76 → 117 columns). The host list
  comes back over the terminal from the icon rail or Ctrl+Shift+S, and goes
  away on Esc, a click outside, or opening a host. Pin it to keep it docked.
- **标签栏** The active tab always scrolls into view, the wheel scrolls the
  tab bar, and a menu lists every tab once they no longer fit. Tabs keep
  their names readable: the engine badge moved to the tooltip and the
  environment shows as an icon (production adds a red top edge).
- **键盘回到终端** Closing the command palette, shortcut list, settings, the
  file panel or a menu puts the keyboard back in the terminal, as do clicking
  a tab or the monitor button.
- **主机列表** One click selects a host; double-click or Enter connects
  (Settings › General can switch back to single-click). Host names come
  first, environment shows as an icon, and the host colour tints the icon
  instead of a dot that looked like an online status. With no hosts yet, the
  window offers one clear first step: New host.
- **新建主机** Address and credentials come first, the name is optional
  (the address is used), and advanced options (jump host, engine, X11, proxy,
  shell integration, keep session, logs) fold away unless a host uses them.
  New hosts get Save and connect; after saving, the host is selected and
  scrolled into view.
- **终端配色** Settings › Terminal › Colour scheme: dark (default), light,
  or follow the app. Desktop, mobile, session logs and the settings preview
  all use it.
- **分屏** The active pane has an accent outline and the other panes dim, so
  it is clear where typing goes; the production marker stays on the tab.
- **快捷键一致** The shortcuts shown in the app work everywhere: on Windows
  and Linux the palette is Ctrl+Shift+K in and out of the terminal (Ctrl+K
  still works outside it), and the shortcut list says which ones also work
  outside the terminal.
- **其他** Ctrl/⌘-click or middle-click a host opens a new session beside the
  current one. Closing a tab or pane that is running a command or a
  full-screen program asks first.

### 更新 / Updates

- **一键更新并重启** The app downloads the update, checks its signature,
  installs it and restarts. On macOS the app bundle is swapped so an
  interrupted install recovers on the next launch; if the restart fails,
  Restart tries again without reinstalling.

### 可靠性 / Reliability

- **大量输出不再断开** When the window falls behind a program printing a lot
  of output (cat of a large log), the session slows the program down
  instead of dropping the connection.
- **文件传输** Overwriting a remote file keeps the original if the upload
  fails (the OpenSSH engine uploads under a temporary name first). Resume
  checks a file before skipping it as finished. Two terminals receiving a
  file with the same name no longer collide. Mobile chunked uploads check
  offsets and the final size.
- **ZMODEM、AI 与其他** A cancelled ZMODEM transfer closes files that open
  late and receiving has a size limit; AI answers can be cancelled mid-read
  and have time and line limits; settings saved at the same time no longer
  overwrite each other; the askpass helper has a read limit.

### 质量 / Quality

- CI and releases install from lockfiles. Pull requests that touch user data,
  concurrency, cancellation or limits must state and test the failure path.
