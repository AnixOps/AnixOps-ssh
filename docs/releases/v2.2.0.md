## AnixOps SSH 2.2.0

### 新功能 / What's new

- **服务器监控** A monitor pane beside the terminal for Linux hosts on the
  built-in engine: CPU, memory, swap, load, network, SSH latency and disks,
  plus a full process list that can sort, filter and end processes.
- **终端断线自动重连** Desktop terminals reconnect on their own after a
  dropped connection or sleep, with backoff and a status bar you can cancel.
- **终端更顺手** Right-click menu, a warning before multi-line paste,
  Ctrl/⌘-click links, OSC 52 clipboard, the remote title in the tab, Option
  as Meta on macOS and current Unicode widths.
- **导入** Import nodes from AnixOps Control (and sync again later), Ansible
  inventories (YAML and INI), and JumpServer assets with direct login
  through KoKo.
- **出站代理** Hosts can connect through a SOCKS5 or HTTP proxy, with an
  AnixOps Net preset.
- **检查更新** Checks the signed AnixOps update feed and tells you about a new
  version; it never installs on its own.
- The Ask AI button only shows once AI is turned on and configured.

### 与 OpenSSH 和主流客户端对齐 / Behaves like OpenSSH

- Sign-in tries keys in OpenSSH's order, asks for a passphrase only after
  the server accepts the key, and uses the saved password for
  keyboard-interactive.
- Host keys are read from every OpenSSH known_hosts file, `@revoked` is
  honoured, and a new key type is treated as new rather than changed.
- ssh_config options the built-in engine used to ignore are honoured or
  handed to OpenSSH; `~` and `~\` expand in key and Include paths.
- Shells get the same terminal modes and UTF-8 locale as from OpenSSH.
- Idle connections are checked before reuse, channel opens time out, and
  MaxSessions limits are worked around.
- Tunnels come back after a dropped connection and show refused
  connections; forwards gain SOCKS4/4a, IPv6 localhost, port 0 and bare IPv6
  addresses.

### 文件 / Files

- Typed paths resolve like a shell; a typed file opens its folder.
- Uploads replace files safely, failed downloads keep finished files, and
  deleting a folder removes everything in it.
- Transfers keep permissions and times, and folders no longer skip links or
  odd names; the OpenSSH backend survives names that are not UTF-8.

### 其他 / Also

- Telemetry scrubbing uses the shared AnixOps redaction vectors.
