## AnixOps SSH 2.4.0

### 连接 / Connections

- **连接失败按阶段说明** A failed connection now says which stage failed
  (DNS, connect, host key, authentication, session, vault) with what to
  check; authentication failures list the methods tried. The card offers
  Retry, Edit host / choose key and Unlock vault, and the raw error sits in
  a details section you can copy.
- **主机密钥核对** The host key dialog explains how to verify a key, lets you
  paste the expected fingerprint to compare (a mismatch blocks replacing),
  and asks before replacing a stored key.
- **重连分隔线与保留会话** A reconnect writes a dim line saying whether this
  is a new shell or the same tmux/screen session. The host editor gets
  Keep session (off, tmux, screen): the terminal attaches to the session on
  each reconnect, and a host without the tool keeps a plain shell with a
  notice. Nothing typed earlier is ever resent.
- **主机环境标记** Hosts can be marked production, staging, testing or
  development. Production shows a badge in the host list, tabs and mobile,
  a red top edge on the terminal, and asks before broadcast input and
  multi-line paste. Search matches the environment; it syncs with the host.

### 文件 / Files

- **SFTP 断点续传** With the built-in engine a failed or cancelled transfer
  keeps its partial file; Resume continues where it stopped when the source
  is unchanged (otherwise it restarts and says so). Folders resume per file
  and skip finished ones. Partials older than 7 days are cleaned up.
- **SHA-256 校验** Optional checksum after each transfer (Settings, off by
  default) and a Verify action per transfer row; a mismatch fails the
  transfer but keeps the file.

### 界面 / Interface

- **设置改为分区式** Settings now opens as a page over the workspace: nine
  categories on the left, one section on the right, and search that lists
  matches from every category. Sessions keep running underneath; Esc
  returns. The Terminal section has a live preview of font, size, line
  height, cursor and ligatures.

### 质量 / Quality

- **性能基准** Reproducible benchmarks for connect time, reconnect and SFTP
  throughput under simulated networks run in CI, and each release carries
  the report (see docs/benchmarks.md).
