## AnixOps SSH 2.0.0

2.0 turns AnixOps SSH from a careful shell over the system OpenSSH into a
local-first, end-to-end encrypted home for your hosts, keys and sessions.
Everything below is free and works without an account.

### 新功能 / What's new

- **内置 SSH 引擎** Built-in SSH engine (russh) is now the default. One
  connection per host carries the terminal, the file pane and tunnels, so you
  sign in once. Hosts that rely on `ProxyCommand`, `Match` and similar
  options keep running on OpenSSH automatically; OpenSSH stays available in
  Settings → Advanced.
- **会话不再随窗口关闭而断开** Sessions live in a background service: closing
  or reloading the window no longer drops them.
- **加密保险库** Encrypted vault for passwords, private keys and key
  passphrases, unlocked with a passphrase, Windows Hello or Touch ID.
- **同步与团队** Optional end-to-end encrypted sync through your own
  open-source `easyssh-server`: devices, signed changes, field-level merge,
  restorable history, and team vaults with roles. Removing a member rotates
  the vault key.
- **导入** Import hosts from OpenSSH config, PuTTY, SecureCRT, MobaXterm,
  Xshell, FinalShell, Termius and CSV.
- **终端** Split panes and broadcast input, shell integration (bash, zsh,
  fish), command completion, AI answers with your own API key (shown before
  sending), and encrypted session recordings.
- **串口** Serial port sessions next to SSH and local shells.
- **全新界面** The whole interface follows AnixOps Design 1.2.0, with a
  keyboard shortcut list on Ctrl/⌘+/.
- **隐私** Crash reports are asked for on first start; usage statistics stay
  off unless you turn them on. Terminal content and host addresses are never
  collected.

### 升级须知 / Upgrading

- Your 1.x hosts, groups, snippets and tunnels move into the new local
  database on first start. The old configuration file is kept next to it.
- 2.x cannot be downgraded to 1.x in place; the kept 1.x file is the way back.
- Git sync is now **Backup to Git** (encrypted export); syncing between
  devices uses the sync server.
- Shortcut change: split down is now **Ctrl+Shift+O**.
