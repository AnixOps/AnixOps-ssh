## AnixOps SSH 2.3.2

### 终端 / Terminal

- **右键菜单** Right-click no longer opens the WebView's own menu (Back,
  Reload, Inspect). Fields get Undo, Cut, Copy, Paste and Select all;
  host, file, snippet and tunnel rows open the same menu as "More"; tabs
  offer Close, Close others, Close to the right. Browser shortcuts (F5,
  Ctrl+R, Ctrl+P, zoom, back/forward) are switched off.
- **重新连接后模式不丢** Reattaching a terminal (reloading the window,
  restoring the layout) restores the modes the program set, so btop and
  similar programs keep mouse input, the alternate screen and cursor style.
- **终端鼠标** Old-style (X10) mouse reports reach programs such as Vim and
  mc; in mouse mode right-click goes to the program (Shift+right-click, or
  Option on macOS, opens the terminal menu); a new setting turns program
  mouse input off.
- **超链接与真彩色** OSC 8 hyperlinks open with Ctrl/⌘+click like other
  links; XTGETTCAP queries are answered, so Neovim and others use 24-bit
  colour over SSH.
- **对齐主流终端** Font zoom (Ctrl+= / Ctrl+- / Ctrl+0, Ctrl+wheel),
  Ctrl+Tab between tabs, Windows Terminal style Ctrl+C / Ctrl+V (a setting,
  on by default on Windows), minimum contrast for ANSI colours in the dark
  theme, a reconnect that no longer draws over the old screen, duplicate
  tab, open host in a new tab, and drag to reorder tabs.

### 文件与连接 / Files and connections

- **二进制文件不进编辑器** Binary files are downloaded instead of opened in
  the editor (by extension, or by a NUL byte in the first 8 KB).
- File pane: sort by column, show hidden files, right-click download and
  copy path, Backspace for the parent folder, and following the terminal's
  directory (OSC 7).
- SFTP uses another connection to the host when one is at MaxSessions.
- Quick connect from the host search box; settings search.

### 界面 / Interface

- **侧栏可收起、专注模式** The sidebar folds (click the current icon,
  Ctrl+B or Ctrl+Shift+S in a terminal), and focus mode (F11 / ⌃⌘Z) shows
  only the terminal. Both are remembered.
- **窄窗口不再挤压** Settings rows no longer squeeze their label to one
  character per line (Files › Editor): a control that does not fit wraps
  under the label, and text fields sit under it at full width. In a narrow
  window the terminal keeps at least 440 px: the monitor folds to its rail
  (expanding it floats it over the terminal) and the files pane floats over
  the terminal. Tab bar buttons show only icons when the bar is narrow.
- Every screen is now checked in CI at the smallest window, in Chinese and
  English, and on a 360 px phone for text that is squeezed, overlapping or
  cut off.
